# קליניק – לקוח React למערכת התורים ClinicQueue

לקוח שמדגים את שרת ה-Web API של ClinicQueue מקצה לקצה: התחברות והרשמה עם JWT, רשימות עם pagination מול השרת, קביעת תור, והצגה ברורה של מקרה שבו התור נתפס על ידי מטופל אחר (409).

**שרת:** _יתווסף קישור_ · **אתר חי:** _יתווסף אחרי ההעלאה_

## מסכים
- **התחברות / הרשמה:** כולל כניסה מהירה למשתמשי דמו (מטופל ומנהל).
- **דף הבית:** חיפוש רופא לפי שם והתמחות.
- **דף רופא:** בחירת יום ושעה ואישור. אם התור נתפס בינתיים, מוצגת הודעה והרשימה מתרעננת.
- **התורים שלי:** רשימה עם pagination וביטול תור.
- **ניהול (Admin):** כל התורים, תורים פנויים ורופאים.

## הרצה מקומית
דרישות: Node.js, ושרת ClinicQueue רץ (ברירת מחדל `http://localhost:5207`).
```bash
npm install
npm run dev
```
האתר עולה ב-http://localhost:5173. כתובת שרת אחרת מגדירים במשתנה הסביבה `VITE_API_URL`.

## טכנולוגיות
React · Vite · React Router · גופן Heebo מקומי. הסמלים מצוירים ב-SVG בקוד, בלי ספריות או תמונות חיצוניות.
